## Featured Projects

### 🏥 MediSync — Smart Healthcare Scheduling Platform

![Status](https://img.shields.io/badge/IN%20PROGRESS-141414?style=flat-square)
![FastAPI](https://img.shields.io/badge/FastAPI-141414?style=flat-square&logo=fastapi&logoColor=A0A0A0)
![PostgreSQL](https://img.shields.io/badge/PostgreSQL-141414?style=flat-square&logo=postgresql&logoColor=A0A0A0)
![Next.js](https://img.shields.io/badge/Next.js-141414?style=flat-square&logo=nextdotjs&logoColor=A0A0A0)
![Redis](https://img.shields.io/badge/Redis-141414?style=flat-square&logo=redis&logoColor=A0A0A0)
![Docker](https://img.shields.io/badge/Docker-141414?style=flat-square&logo=docker&logoColor=A0A0A0)

A production-grade appointment scheduling system built for clinics and multi-specialty practices. This is the project where I put every stage of the software journey into practice simultaneously.

**The full journey on this one:**
- Wrote the SRS, defined 3 actor roles, mapped all use cases before touching code
- Designed a 9-table PostgreSQL schema — timezone-aware datetimes, immutable audit trail, Waitlist & Notifications tables, RBAC join tables
- Architected ~100 REST endpoints across 16 categories with Alembic migrations
- Built complete dashboards for Admin, Receptionist, and Provider roles in Next.js 14
- Implemented Redis sorted sets for provider queues, distributed lock patterns for concurrency
- WebSocket real-time updates + priority waitlist with auto provider assignment
- Containerized with Docker Compose: FastAPI + PostgreSQL + Redis + Nginx

![Django](https://img.shields.io/badge/Django-141414?style=flat-square&logo=django&logoColor=A0A0A0)
![PostgreSQL](https://img.shields.io/badge/PostgreSQL-141414?style=flat-square&logo=postgresql&logoColor=A0A0A0)
![Redis](https://img.shields.io/badge/Redis-141414?style=flat-square&logo=redis&logoColor=A0A0A0)

![Docker](https://img.shields.io/badge/Docker-141414?style=flat-square&logo=docker&logoColor=A0A0A0)

A full-stack platform where I had to solve real performance problems — not just build CRUD endpoints.

**What makes this different:**
- Geospatial search using Haversine formula + Django ORM optimization → **40% faster queries**
- AI-driven adoption screening and suitability scoring via Google GenAI
- Intelligent booking conflict resolution engine — not just "is the slot free" logic
- Secure RBAC with cookie-based JWT + Django-Q background task queues
- Shipped to production with Docker — not just running locally
